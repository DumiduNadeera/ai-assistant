# Payment Settlement Delay

Document ID: INC-2025-0061
Department: Payments
Document type: Incident
Access level: Internal
Created date: 2025-05-03

## Root Cause

Settlement processing lagged when a database query plan changed and consumed excessive worker capacity. Delayed queue consumers increased end-to-end processing time.

## Impact

Settlement reports were delayed by 52 minutes. Customer authorization remained available.

## Corrective Actions

Pin critical query plans, monitor queue age, and set worker saturation alerts.
